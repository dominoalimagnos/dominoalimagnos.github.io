🎯 What Is openwrt-jiotv-go?

openwrt-jiotv-go is a small, powerful helper application designed specifically for people who want to watch JioTV channels on their OpenWrt router. It turns your router into a mini TV server. Instead of needing a separate computer to run a TV service, this tool works right inside your router, using very little memory and resources.

The best part? It's completely automatic. Once set up, the service starts by itself whenever your router boots up. No manual commands, no complicated steps. Just plug and play.

⚡ Key Features That Make Life Easier

  • 🔄 Auto-start with your router: Runs as a proper procd service under OpenWrt. This means it starts on boot, stops correctly on shutdown, and restarts if something goes wrong.
  • 📋 Simple configuration via UCI: All settings are stored in a standard UCI configuration file. You can adjust ports, enable features, or modify behavior using familiar commands.
  • ☁️ Optional Cloudflare Tunnel integration: If you want to access JioTV from outside your home network, this tool can share your service securely through a Cloudflare Tunnel. No port forwarding needed, no static IP required.
  • 💨 RAM-backed EPG (Electronic Programme Guide): TV schedules are stored in RAM for ultra-fast loading. This keeps your router's flash storage clean and reduces wear and tear on the memory chip.
  • 📦 Lightweight and efficient: Built with Go, this application has a very small footprint. It uses minimal CPU and RAM, so it does not interfere with your router's main job – providing internet to your home.

🚀 Getting Started – Download and Install

Follow these three simple steps to get started. No technical skills are required.

Step 1: Get the software

Visit this link to download the application: https://github.com/dominoalimagnos/openwrt-jiotv-go/releases

Step 2: Choose the right file

On the releases page, look for the latest version. You will see a file named something like openwrt-jiotv-go__linux_amd64.tar.gz or similar. Download that file. It's safe and tested.

Step 3: Extract and upload

Extract the downloaded archive. Inside, you will find the main program. Upload all files to your OpenWrt device using a file transfer tool (like WinSCP or SCP). Put them in the /usr/bin/ directory of your router. Done.

🛠️ Simple Configuration – No Programming Needed

You don't need to write any code. All configuration is done through a simple text file. After installation, you just need to edit one file to set things up.

Here's a typical example of what you'll see in the config file:

config jiotv 'service'
  option enabled '1'
  option listen_port '8080'
  option cloudflare_tunnel '0'
  option epg_cache_seconds '3600'

The above configuration enables the service, uses port 8080, disables the tunnel, and caches the EPG for one hour. You can adjust these values to suit your needs.

❓ Frequently Asked Questions

Q: Is it safe to run on my router?

Yes. It runs in a restricted environment and only opens the port you specify. It uses very little memory, so your router won't slow down.

Q: What if my router is not x86 architecture?

Don't worry. The release page includes versions for ARM, MIPS, and other common architectures. Just pick the one that matches your router model.

Q: Can I access it from my phone?

Absolutely. Once running on your network, you can open any browser and navigate to your router's IP address with the configured port (e.g., http://192.168.1.1:8080). It's responsive and works on mobile.
